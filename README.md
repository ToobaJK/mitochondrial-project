# mitochondrial-project
R scripts and analysis workflows used to generate figures and investigate mitochondrial metabolism for a research study.
## Data Availability

Due to GitHub file size limitations, large datasets used in this project are not included in this repository.

These datasets include (but are not limited to):
- TCGA gene expression data 
- CCLE RNA-seq datasets
- CRISPR gene effect data
- Drug repurposing datasets (cell line metadata, treatment data, LFC values)
- miRNA datasets 
- Other large intermediate and processed data files

### Data Sources
These data can be downloaded from their original sources:

- UCSC Xena Browser: https://xenabrowser.net/
- CCLE / DepMap: https://depmap.org/
- Other datasets: see corresponding publications or data portals

### Usage
After downloading, place the datasets into a local `data/` directory before running the scripts.
